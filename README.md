# Morgana Spraute

App de música e ritmo para a Morgana (4 anos). Página única em HTML, CSS e JS, sem dependências.

## Como publicar no GitHub Pages
1. Crie um repositório e envie todo o conteúdo desta pasta (inclusive `sons/` e `fotos/`).
2. Em **Settings > Pages**, escolha **Deploy from a branch**, branch `main`, pasta `/ (root)`.
3. Abra o endereço `https://SEU-USUARIO.github.io/NOME-DO-REPOSITORIO/` (precisa ser HTTPS para o microfone funcionar).

## Arquivos
- `index.html` - o app inteiro
- `logo.webp` - logo da tela inicial
- `fotos/1-4.webp` - fotos da Morgana
- `sons/*.mp3` - vozes e sons enviados

## Jogos
1. Toque as músicas (Golden, Anunciação, Parabéns, Brilha estrelinha, Ode à alegria, Maria tinha um carneirinho, Escala)
2. Siga o ritmo
3. Jogo da memória
4. Piano livre

O botão "Tocar no teclado" usa o microfone para ouvir o teclado de verdade.
